# A-bank-system-using-only-python

A simple Python console application for managing bank accounts with separate **Customer** and **Admin** portals.
This project is use to showcase or as a checkpoint for my knowledge of python.
---

## 🛠️ Requirements & Setup

1. Make sure Python 3 is installed.
2. Place all project files (`main.py`, `BankAdmin.py`, `savingAcc.py`) in the same folder.
3. Open your terminal in the project folder and run:
   ```bash
   python main.py
